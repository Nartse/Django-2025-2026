# OOP-Based Todo App (JSON Storage)

A simple Command Line Interface (CLI) Todo application built using Python and Object-Oriented Programming (OOP).  
All tasks are stored locally in a JSON file so data persists even after restarting the program.

---

## 🚀 Features

- Add new todos  
- View all todos  
- Update todo title  
- Mark todos as completed or not completed  
- Delete todos  
- Automatic saving using JSON  

---

## 🛠 Technologies Used

- Python 3  
- Object-Oriented Programming (OOP)  
- JSON for local storage
